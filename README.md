
# 📌 reservasalles - Système de Réservation de Salles
## 📖 Description
"reservasalles" est un site web permettant de réserver des salles pour différents événements (mariage, conférences, etc.).

Les utilisateurs peuvent consulter les salles, effectuer des réservations et télécharger des reçus de paiement.

## 🚀 Technologies utilisées
- React
- Tailwind CSS
- Supabase
- Vercel

## 🧠 Fonctionnalités
- Consulter les salles disponibles
- Réserver une salle
- Télécharger un reçu de paiement
- Voir le statut des réservations
- Gestion admin (salles & réservations)
- 
## 🏗️ Architecture
- Frontend : React typescript tailwind
- Backend & Database : Supabase
- Déploiement : Vercel

## 🗄️ Base de données
Tables principales :
- profiles
- halls
- bookings

## 🔐 Sécurité
- Authentification avec Supabase
- Row Level Security (RLS)
- Gestion des rôles (admin / user)
